Tiny Alpha-Beta: a 3,879-byte chess engine in a single packed main.py — alpha-beta search with quiescence, piece-square tables, a transposition table, killer moves, null-move pruning and late move reductions, at a fixed 45,000 nodes per move. Practice Elo 1,451 across three graded trials (floor 1,154; sunfish baseline mean 1,365). Python 3.13 standard library only, no network, no other files read.

## Run it

The engine is played by the make.fun trial harness. To grade it locally, use the competition kit's grade-local command (see the kit's Grade locally section).
